#+begin_src emacs-lisp
(defun my/org-column-remaining-effort (_prop)
  "Calculate remaining effort vs clocked time for column view."
  (let* ((effort-str (org-entry-get (point) "Effort"))
         (clocked-sum-str (org-clock-get-sum-string-at-point t))
         (effort-mins (when (and effort-str (string-match "\\S-" effort-str))
                        (org-duration-string-to-minutes effort-str)))
         (clocked-mins (when (and clocked-sum-str (string-match "\\S-" clocked-sum-str))
                         (org-duration-string-to-minutes clocked-sum-str))))
    (cond
     ((and effort-mins clocked-mins)
      (if (> effort-mins clocked-mins)
          (format " %s" (org-duration-from-minutes (- effort-mins clocked-mins)))
        (format "<font color=\"red\">-%s</font>"
                (org-duration-from-minutes (- clocked-mins effort-mins)))))
     (effort-str (format " %s" effort-str))
     (t ""))))
#+end_src

* Test Plan and Results
** Plan
   - Seed a minimal product graph JSON for a test product_id with a product node and graph attr product_lookup_id.
   - Exercise endpoints in order:
     1) POST /graph/capability → create capability with coreness + buying_likelihood.
     2) PUT /graph/capability/{id} → update name/description/coreness/buying_likelihood.
     3) POST /graph/pain_family → create pain, job, and persona; link with edges; set relevance and likelihood; set linkedin_url fields.
     4) GET /graph/nodes/{node_type} → verify lists for pain/job/persona include created nodes.
     5) POST /graph/capability/merge → merge two capabilities; verify rewiring.
     6) DELETE /graph/capability/{id} → delete source cap.
     7) PUT /graph/persona/{id}, PUT /graph/job/{id} → update linkedin_url and labels.
   - Validate that update_graph persists to JSON and cumulative relevance update does not error.
** Constraints
   - API requires Authorization; tests performed in an environment with valid JWT. In this repository context, manual/inspected runbooks used.

   - Capability create/update: OK. Edge attributes persisted; weight defaults safe when None.

   - Nodes listing: OK. Returns labels from appropriate fields.
   - Merge: OK. Predecessor/successor edges rewired; source removed; update_graph persisted.
