* Cognitive Bias Guardrails
** Outside View – Question Set
   - If a colleague with similar skills were assigned this task, what would my estimate be for them?
   - What data from archived tasks contradicts my current estimate?
   - What is the worst-case scenario and buffer?
   - Am I making a promise or a hope? What changes make it a promise?
